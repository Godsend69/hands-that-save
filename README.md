# Hands That Save

A hands-only VR first-aid game (WebXR, built with Meta's Immersive Web SDK).
Play: https://godsend69.github.io/hands-that-save/ (open in the Meta Quest browser, touch "Enter VR").

Not certified CPR training - learn CPR in a certified course.
Steps follow the European Resuscitation Council (ERC) Guidelines 2025 for adult basic life support. 112 is the EU emergency number.

This repository holds the built web files only.
