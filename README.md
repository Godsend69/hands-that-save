# Hands That Save

A hands-only VR first-aid game (WebXR, built with Meta's Immersive Web SDK).
Play: https://godsend69.github.io/hands-that-save/ (open in the Meta Quest browser, touch "Enter VR").

Not certified CPR training - learn CPR in a certified course.
Steps follow the European Resuscitation Council (ERC) Guidelines 2025 for adult basic life support. 112 is the EU emergency number.

This repository holds the built web files only.

## Crash reports (FIELD REPORT)
From build 20261111-28c69ae the game sends anonymous crash reports and two events (page opened, VR entered) to our own
receiver at reports.lightinthedarksolutions.com, so bugs on real headsets can be found and fixed. Each report holds
the build id, the browser and device line, the screen size, whether WebXR is present, a random id kept in the
browser, and the last console lines. No name, no account, no cookies. The start screen says so in one line.
Nothing changes in the gameplay.
